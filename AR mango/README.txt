Welcome to Anime Ranger Macro (a Roblox game) - made by KuruDev (im a noob dev)

To make this Macro basically works included:

Main.ahk - run the macro
Function.ahk - a bridge between macro function and GUI
Image.ahk - store images for searching
GUI.ahk - for GUI and interact

Logs for debug
Findtext.ahk is developed function from ahk community, do not change it, use for macro searching

There's also libraries files for macro function

game flow: 
 - start macro
 - startselectedmode (challenege, ranger,...then for the movement)
 - restartstage (deteced map, check loaded and votestart), use for replaying game
 - monitorstage is while playing the game, monitorendscreen is when the game show up victory or defeat (mean end game) text
 - if returned back to lobby, turn back to startselectedmode and restartstage

This macro is free since i borrow it from another dev team, you can operate or do anything you want
